# 青花缠枝牡丹纹瓶：首页主视觉与真实器型提取设计

## 目标

把用户提供的青花缠枝牡丹纹瓶 GLB 作为纹脉的首件青花主器型。首页优先展示该器型；文物纹样提取页默认进入青花模式。青铜器扫描模型保留在次级分类，继续承担考古扫描体验。

## 资产与加载

首批使用两件用户生成的青花器型：`C:\Users\lenovo\Downloads\e384427da9f179c900ea612a313a99f3.glb`（约 81.81MB）与 `C:\Users\lenovo\Downloads\93113cd6c63cf761de15cca8b63626a0.glb`（约 84.06MB）。两者均为 glTF 2.0、单网格、三张 4096px 贴图并带一段动画。第一件作为首页主器型，第二件作为提取页可切换的青花器型。发布资源只使用压缩后的副本，原文件不修改。

压缩目标是保留瓶身轮廓、青花纹样清晰度和嵌入动画，减少网格与贴图体积。若压缩结果无法保持缠枝牡丹纹可辨，保留较高纹理分辨率并以首页缩略图兜底；首页永远先显示缩略图或点云，不出现黑色等待区域。

## 首页

首页默认器物替换为青花缠枝牡丹纹瓶。点云入场按照瓶形收束，颜色从钴蓝点、暖白微光过渡到真实瓷瓶。现有五尊鼎移入“考古器物”横向选择带，仍可左右切换与查看；青花瓶始终排在第一个。

首页材质、灯光和文字色以暖白釉面与钴蓝为主。模型点击仍展开器物说明，说明卡提供“进入纹样提取”入口，并带 `m=qinghua_peony` 参数进入同一器型。

## 纹样提取页

顶部提供清晰的“青花瓷”和“考古扫描”分类。页面默认分类为青花瓷，默认模型为青花缠枝牡丹纹瓶；考古扫描分类展示现有青铜器。

每件青花瓶使用真实 GLB 与独立的纹样标注 manifest。第一版仅标注前方可见、轮廓完整的主纹带及其辅助边饰。用户点击高亮纹样后获得对应裁切纹样卡，卡片包含来源器物、纹样名称、类别与图片，并可进入拼图创作。系统不把单视角可见区域表述为完整 360° 自动提取。

模型切换时清空本轮提取状态，右栏只显示当前器物对应的纹样卡。分类和器物切换器在页面上常驻可见。

## 标注与数据边界

青花瓶 manifest 独立放在其模型目录，不能复用青铜器的 UV 或元素图片。标注数据包含元素编号、名称、主纹/边饰等级、点击区域和提取卡图片。提取卡由该青花瓶贴图裁切或经人工确认的局部图生成，保证与模型表面对应。

缺少多角度图像或 3D UV 标注时，只提供已验证的正面纹样带，不虚构背面、侧面或未见区域的纹样。

## 验收

- 首页首屏可见青花缠枝牡丹纹瓶的缩略图或点云，随后无黑屏切换至模型。
- 点击首页青花瓶能进入 `#/relic?m=qinghua_peony`。
- 提取页默认在青花瓷分类，模型、标题、纹样卡和来源信息一致。
- 青铜器可从“考古扫描”切换进入，原有提取不回归。
- 移动端选择器、信息卡与提取按钮没有遮挡；减少动态设置下仅显示静态过渡。
- `npm run test -- --run` 与 `npm run build` 通过。
