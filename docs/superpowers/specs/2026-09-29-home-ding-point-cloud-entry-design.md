# 首页鼎点云入场设计

## 目标

首页首尊错金银鼎在 GLB 加载期显示金色点云收束与扫描线，真实器物在点云完成后出现，替换现有纯黑等待。

## 范围

试作只作用于首页默认的错金银鼎。左右切换的其他器物继续使用原有缩略图过渡；文物详情页不改变。

## 时序

首页打开后立即绘制点云。点云在至少 1.8 秒内收束成鼎形，并持续显示直到首尊 GLB 完成首帧绘制；随后在 0.55 秒内淡出，真实鼎从微下方升入。点云没有网络或模型依赖。

## 验收

1. `#/home` 首屏不出现纯黑模型等待区。
2. 首尊鼎进入前可见金色点云和扫描线。
3. 首尊模型加载慢时点云持续可见；加载完成后模型出现。
4. 切换其他器物、拖拽和点击进入文物页维持现有行为。
