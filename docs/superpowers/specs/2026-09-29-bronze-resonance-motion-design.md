# 青铜共鸣动效设计

## 目标

为纹脉增加一套克制、可复用的动态视觉语言。它以首页大鼎为主角，增强加载、触碰和任务完成时的到场感，不影响识纹、拼图、创作的操作速度和信息阅读。

## 视觉方向

采用“青铜共鸣”：深墨绿背景上的古金与玉绿微光。大鼎仍是唯一大尺度视觉主体；点云、光环和纹样粒子只负责引导视线，不覆盖器物或文字。

不采用持续大面积扫描、强闪烁或高密度碎片动画，避免使文化内容变成装饰性特效。

## 首页

`HomeHero3D` 的现有点云入场保留。模型可用时，点云沿器形轮廓向实体收束；模型加载失败时，保留已有缩略图兜底，不展示空黑画面。

用户点击大鼎时，在模型周围播放一次短促的椭圆形金绿光环，并让极少量纹样点从腹部向外扩散后消失。现有器物信息面板继续出现，交互入口不改变。光环不拦截点击，也不改变相机或路由。

首页工具入口和内容卡片只使用低对比度的边缘流光：进入视口时播放一次，静止时不循环。避免增加初次渲染的网络资源。

## 其他页面

识纹结果、拼图完成和作品发布成功各使用一次相同的“从中心聚拢、向外淡出”反馈。动效以 CSS/SVG 或已加载的 Three.js 资源完成；不引入第三方依赖，不请求新素材。

页面路由切换维持现有节奏，只为内容区增加短暂淡入，不遮挡返回、底部导航和表单控件。

## 性能与无障碍

通过 `prefers-reduced-motion: reduce` 禁用粒子、光环和页面过渡，只保留静态渐变。粒子数、设备像素比与渲染循环受限，移动端优先降低数量而非延迟主内容。

动效节点设为装饰性，不写入焦点顺序，不影响屏幕阅读器。所有功能都能在动效被禁用时照常完成。

## 验收

- 首页从加载到大鼎可见不再出现纯黑等待态。
- 点击大鼎能看到一次光环和纹样点反馈，并能正常打开器物说明。
- 三个任务完成场景各有一次统一反馈，操作按钮可立即使用。
- 减少动态模式下没有持续动画或粒子。
- `npm run build` 与现有测试通过；手机宽度下无溢出或遮挡。
