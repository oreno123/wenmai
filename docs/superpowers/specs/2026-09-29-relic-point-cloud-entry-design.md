# 器物点云进入试作设计

## 目标

为 3D 文物提取页的默认青铜簋增加一次点云扫描显影：用户从首页进入时，先看见金色稀疏点云聚合为器形，再显出真实扫描模型，避免模型加载阶段的纯黑画面。

## 范围

试作只作用于默认器型 `shang_gui`。它使用独立的 2D canvas 覆盖层，不改 GLB、纹样提取、相机控制或其他器物的加载逻辑。

## 交互与时序

点云在 1.8 秒内从画面周缘收束成簋的轮廓与腹部密度；之后保持微弱呼吸与扫描线。真实 GLB 就绪后，点云在 0.55 秒内消失，模型与交互立即可用。若 GLB 较慢，点云持续显示，直到模型就绪。

## 验收

1. 进入 `#/relic` 时不再只有纯黑等待。
2. 默认青铜簋加载完成前可见金色器形点云和扫描线。
3. 模型加载后点云自动退出，不遮挡旋转、缩放和纹样提取。
4. 其他器物切换不触发本次试作。
