02一句话理解

用户像玩抽卡游戏一样收集中国传统纹样（团龙、莲花、回纹、青花、山海经异兽……），再把纹样的「元素块」在画布上自由拼贴成作品，实时预览印到马克杯 / 手机壳 / 盘子 / 丝巾上的效果，未来可直接下单定制。

闭环：抽卡收集 → 拼图创作 → 3D 预览 → 分享 / 发布社区 → （远期）下单印刷

03八大模块速览

纹样图鉴

9 个系列收藏浏览 + 稀有度筛选；586 行结构化百科卡片（朝代、文化意义、用途、冷知识）。

Library · PatternDetailPage
抽卡收集

单抽 / 十连双模式，3 档稀有度（common / rare / SSR），软保底 75 抽 + 硬保底 90 抽，每日免费 10 次自动重置。

GachaPage · gameStore
拼图创作 核心

形状级物理交互：mask 像素碰撞 + 边缘吸附 + 柔性块自动变形贴合；角花 4 角对称；6 个预设构图模板；宣纸色画布渲染。金线元素块 + AI 元素库（purpose 二级筛选）。

PuzzlePage · engine/jigsawEngine · shapeInteraction
3D 浮雕预览

金线纹样 → Sobel 算子法线贴图 → 金属浮雕；青花瓷 → meshPhysicalMaterial + clearcoat 釉面瓷盘；马克杯 / 手机壳 / 盘子 / 丝巾实时贴图预览。

react-three-fiber · shaders/

PhotoMatchPage · VITE_STEPFUN_API_KEY

MediaPipe Hands 摄像头手势：左右滑动翻页 + 双手缩放；金色粒子特效（指尖尾迹、滑动弧光、双手间金色丝线）。
